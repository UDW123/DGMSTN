# DGMSTN
A Dynamic Graph-Enhanced Bi-Mamba Spatio-Temporal Network for Long-Term Traffic Forecasting
## Abstract
Accurate traffic flow forecasting is critical for the efficient operation of intelligent transportation systems. Existing spatio-temporal graph neural networks often experience rapidly declining accuracy in long-term predictions, and their complex modeling mechanisms incur high computational and memory costs. We propose a Dynamic Graph-enhanced Bidirectional Mamba Spatio-Temporal Network (DGMSTN), which integrates dynamic graph convolution with Mamba to effectively tackle the aforementioned issues. Specifically, the proposed method adopts Mamba as the backbone for temporal modeling and encodes historical traffic sequences using dual MambaBlocks, where the forward and backward Mamba structures jointly capture long-range temporal dependencies. Meanwhile, the model generates dynamic spatial representations from a learnable node bank, which are embedded into Chebyshev graph convolution for adaptive modeling of complex spatial dependencies. Finally, multi-scale spatio-temporal features are projected into the prediction space through parallel feature fusion and temporal mapping mechanisms to generate the traffic flow forecasts. Extensive experiments on four real-world traffic datasets demonstrate that DGMSTN consistently outperforms multiple state-of-the-art methods across various forecasting horizons. In addition, we further validate the efficiency of the model on two of the datasets, thereby verifying the effectiveness of bidirectional Mamba temporal modeling and node bank-enhanced dynamic graph convolutions for long-term and efficient traffic forecasting.
